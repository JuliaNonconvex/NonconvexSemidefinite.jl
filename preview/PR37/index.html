NonconvexSemidefinite

Description

If you need to keep your any matrix-valued function of the decision variables positive semidefinite, Nonconvex supports an interface for the barrier method for semidefinite programming, which is a meta-algorithm transforming the optimization problem to a series of nonlinear programming problems and solving them using the pre-specified sub_alg and sub_options.

See Quick start for the first steps, the quadratic re-parameterization and the general barrier method for the algorithm internals, Options and optimizer for the configuration, the matrix interfaces, projection utilities, chordal decomposition utilities and modeling helpers for the API, Theory for the algorithmic background and Docstrings for the full API reference.

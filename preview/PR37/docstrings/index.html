NonconvexSemidefinite.AMDAlg — Type
AMDAlg()

The default chordal-extension algorithm: SuiteSparse's approximate minimum degree ordering (AMD.jl) followed by the symbolic Cholesky elimination.

NonconvexSemidefinite.AbstractChordalAlgorithm — Type
AbstractChordalAlgorithm

The algorithms for computing the chordal extension of a sparsity pattern. The built-in, dependency-light ones are AMDAlg (the default: SuiteSparse's approximate minimum degree ordering) and MCSAlg (maximum cardinality search); MFAlg, METISAlg and BTAlg use the optional CliqueTrees.jl dependency.

NonconvexSemidefinite.ArrowIntersection — Type
ArrowIntersection(k, l, dofs)

An interface of the arrow decomposition: dofs are the global degrees of freedom shared by subdomains k and l (k < l), i.e. I_k ∩ I_l; the fictitious load g_{k,l} ∈ ℝ^{|dofs|} lives on it.

NonconvexSemidefinite.ArrowSubdomain — Type
ArrowSubdomain(Kfun, f, I)

One subdomain of the arrow decomposition (arrow_decompose): Kfun maps the design variables to the subdomain stiffness matrix K⁽ᵏ⁾(x) = Σ_{i∈Dₖ} xᵢKᵢ (the elements of the subdomain only, an |I| × |I| matrix in the global dof ordering), f is the load vector restricted to the subdomain's degrees of freedom I (global dof indices).

NonconvexSemidefinite.BTAlg — Type
BTAlg()

An exact (optimal treewidth) algorithm (CliqueTrees.jl): the smallest maximal cliques, at exponential worst-case cost. Requires the optional CliqueTrees.jl dependency.

NonconvexSemidefinite.BarrierAlg — Type
BarrierAlg(sub_alg)

A meta-algorithm that handles inequality, bound and semidefinite constraints using a primal log-barrier approach. The barrier coefficient is decayed across a sequence of sub-problems (see BarrierOptions) and each sub-problem is solved with sub_alg, which must handle the constraints that are not barrierified. SDPBarrierAlg is an alias.

NonconvexSemidefinite.BarrierOptions — Type
BarrierOptions(; kwargs...)

The keyword arguments which can be specified are:

  • c_init: (default 1.0) initial value for the barrier coefficient, a real number or a vector with one entry per barrierified constraint group.
  • c_decr: (default 0.1) decreasing rate (< 1) multiplying the barrier coefficient every iteration, a real number or a vector.
  • n_iter: (default 20) maximum number of sub-problems to solve.
  • sub_options: options for the sub-problem's solver.
  • keep_all: (default false) if set to true, the result stores the sub-problem results from all the iterations.
  • barrier: a BarrierSelection (default: barrierify the semidefinite constraints only).
  • adaptive: (default false) decay the barrier coefficient with a superlinear schedule targeting tol within n_iter iterations instead of the fixed c_decr factor.
  • tol: (default nothing) stop early when the estimated duality gap c ⋅ m (barrier coefficient times the number of barrier terms) falls below this value.
NonconvexSemidefinite.BarrierResult — Type
BarrierResult

Alias of SDPBarrierResult.

NonconvexSemidefinite.BarrierSelection — Type
BarrierSelection(; ineq = false, box = false, sd = true)

Selects which constraint kinds are converted to barrier terms by BarrierAlg. Each entry is true (all constraints of that kind), false (none) or a vector of constraint indices (those only). Equality constraints can never be barrierified and are always kept for the sub-solver.

The default selects semidefinite constraints only, preserving the historical SDPBarrierAlg behaviour; pass BarrierSelection(ineq = true, box = true) to barrierify inequalities and variable bounds as well.

NonconvexSemidefinite.BlockSDConstraint — Type
BlockSDConstraint

A semidefinite constraint whose function returns a vector of matrices (one per block) from a single evaluation. chordal_decompose uses it to evaluate the matrix-valued function once and slice every clique block from that single evaluation instead of re-evaluating it per clique.

The function must return a Vector (or tuple) of symmetric matrices of sizes dims.

NonconvexSemidefinite.MCSAlg — Type
MCSAlg()

Maximum cardinality search ordering (Tarjan–Yannakakis) followed by the symbolic Cholesky elimination. Built in: a chordal graph's extension is itself (no fill), since the reverse of an MCS numbering is a perfect elimination ordering.

NonconvexSemidefinite.METISAlg — Type
METISAlg()

Nested dissection via the METIS library (CliqueTrees.jl): often the smallest cliques on large 2D/3D mesh patterns. Requires the optional CliqueTrees.jl dependency.

NonconvexSemidefinite.MFAlg — Type
MFAlg()

Minimum fill heuristic (CliqueTrees.jl): usually smaller fill than AMD at a higher cost. Requires the optional CliqueTrees.jl dependency.

NonconvexSemidefinite.PSDMatrixView — Type
PSDMatrixView(offset, dim)

A view of an dim×dim positive semidefinite matrix variable added to a model with add_psd_variable!. Calling M(x) decompresses the symmetric matrix from x using decompress_symmetric:

  • if length(x) == nvars(M), x is the variable chunk [x_L; x_D] itself;
  • otherwise x is the full flattened variable vector and the chunk is read at the offset recorded when the variable was added.
NonconvexSemidefinite.SDCuttingPlaneAlg — Type
SDCuttingPlaneAlg(sub_alg)

Cutting-plane meta-algorithm for models with semidefinite constraints (SDConstraint and PSDCone components of function-in-set constraints): the PSD constraints are dropped from the subproblems and reintroduced as linear cuts v'P(x)v ≥ 0 from the most negative eigenpair of each violated matrix, computed with an iterative eigensolver (ARPACK). sub_alg solves the NLP subproblems (e.g. IpoptAlg()); it must handle the model's equality, inequality and box constraints.

NonconvexSemidefinite.SDCuttingPlaneOptions — Type
SDCuttingPlaneOptions(; eig_tol = 1e-5, max_cuts = 100, max_iterations = 10,
                        block_size = nothing, sub_options = NamedTuple())

Options of SDCuttingPlaneAlg:

  • eig_tol: eigenvalue feasibility tolerance — the algorithm stops once every PSD constraint (block) has smallest eigenvalue ≥ -eig_tol.
  • max_cuts: the maximum total number of cuts added.
  • max_iterations: the maximum number of subproblem solves.
  • block_size: the size of the diagonal blocks the iterative eigensolver is applied to (nothing = the whole matrix). Block cuts are valid inequalities; with blocks matching a chordal clique structure the enforced condition is the clique-submatrix (relaxation) one.
  • sub_options: the options passed to the sub-solver.
NonconvexSemidefinite.SDCuttingPlaneResult — Type
SDCuttingPlaneResult

The result of SDCuttingPlaneAlg with fields:

  • minimum: the objective value at the returned minimizer.
  • minimizer: the point found by the last subproblem solve.
  • n_cuts: the total number of cuts added.
  • min_eigvals: the worst eigenvalue (over all PSD constraints/blocks) after each iteration; the last entry is ≥ -eig_tol when the algorithm converged.
NonconvexSemidefinite.SDDPartition — Type
SDDPartition(interiors, interface, n)

A subdomain partition of n degrees of freedom: interiors[k] are the dofs interior to subdomain k (in the original numbering) and interface the dofs shared by several subdomains. See sdd_partition.

NonconvexSemidefinite.SDPBarrierAlg — Type
SDPBarrierAlg(sub_alg)

Alias of BarrierAlg. Historically the barrier meta-algorithm only handled semidefinite constraints; the generalized BarrierAlg now also barrierifies inequalities and variable bounds, selected through BarrierSelection. Both names construct the same meta-algorithm.

NonconvexSemidefinite.SDPBarrierOptions — Type
SDPBarrierOptions(; kwargs...)

Alias of BarrierOptions (all keyword arguments are shared).

NonconvexSemidefinite.SDPBarrierResult — Type
SDPBarrierResult

The result of BarrierAlg (or its alias SDPBarrierAlg) with fields:

  • minimum: the best objective value over the sub-problem sequence.
  • minimizer: the minimizer attaining minimum.
  • results: if keep_all = true in BarrierOptions, the full sub-problem trajectory as a vector of (objective, minimizer) pairs; nothing otherwise.
  • optimal_ind: if keep_all = true, the index of the best sub-problem result in results; nothing otherwise.
NonconvexSemidefinite.SDPQuadAlg — Type
SDPQuadAlg(sub_alg)

Meta-algorithm eliminating semidefinite constraints through quadratic re-parameterization. Every semidefinite constraint of the model must be a decompress_symmetric-style matrix variable chunk in the (x_L, x_D) layout, and the model variables must consist exactly of those chunks. The re-parameterized problem is solved with sub_alg.

NonconvexSemidefinite.SDPQuadOptions — Type
SDPQuadOptions(; sub_options, rank = nothing, diag_floor = 1e-6)

Options of SDPQuadAlg: rank = nothing selects the full-rank Cholesky re-parameterization A = L Lᵀ (with diag(L) ≥ diag_floor bounds); rank = r selects the Burer-Monteiro low-rank re-parameterization A = R Rᵀ with R ∈ R^{n×r}.

NonconvexSemidefinite.SDPQuadResult — Type
SDPQuadResult

The result of SDPQuadAlg with fields:

  • minimum: the objective value at the minimizer.
  • minimizer: the minimizer in the (x_L, x_D) variable layout of the original model, i.e. the decompressed entries of the re-parameterized factor variables.
NonconvexSemidefinite.add_psd_variable! — Method
add_psd_variable!(model, dim; init = I(dim))

Add the variables of a symmetric dim×dim positive semidefinite matrix to the model as one chunk in the (x_L, x_D) layout (the strict lower-triangular entries followed by the diagonal), with the diagonal constrained to be non-negative. Returns a PSDMatrixView that decompresses the matrix from a variable vector.

model = Model()
M = add_psd_variable!(model, 3)
model.objective = x -> -loglikelihood(MvNormal(μ, M(x[1])), samples)
NonconvexSemidefinite.aggregate_sparsity — Method
aggregate_sparsity(f, x0::AbstractVector, dim::Int)

Structural sparsity pattern of the matrix-valued function f (returning a dim×dim matrix) at x0, computed with reverse-mode AD: entry (i, j) is structurally nonzero if f(x)[i, j] depends on any variable.

NonconvexSemidefinite.arrow_decompose — Method
arrow_decompose(model::VecModel, subdomains, intersections;
                x0 = model.init, labels = nothing)

Kočvara's arrow decomposition (Theorem 2.3 of Kočvara, Math. Program. 2021): rewrites the minimum-compliance SDP constraint Z(x, γ) = [K(x) f; fᵀ γ] ⪰ 0 (dimension n+1, with the design x first and γ the last variable) into one PSD constraint per subdomain,

[ K⁽ᵏ⁾(x)  f⁽ᵏ⁾ + g⁽ᵏ⁾ ; (f⁽ᵏ⁾ + g⁽ᵏ⁾)ᵀ  γₖ ] ⪰ 0,

replacing the matrix-sized coupling variables of the chordal decomposition by the vector fictitious loads g_{k,ℓ} on the interfaces and the scalars γₖ (the objective becomes Σₖ γₖ). The transformation is exact: Σₖ Z⁽ᵏ⁾_B = Z(x, Σₖγₖ).

subdomains is a vector of ArrowSubdomains (their dof sets may overlap on the interfaces) and intersections the ArrowIntersections with k < l. labels selects the PSD constraint to decompose (exactly one must be selected; labels = nothing selects all, which must then be a single PSD component). Returns (dmodel, d0, mapper) with the new variables (γₖ then the g_{k,ℓ}) appended after the original ones.

NonconvexSemidefinite.assemble_chordal — Method
assemble_chordal(Ys, cliques, n)

Assembles the clique matrices Ys (the |Cₖ| × |Cₖ| block of the maximal clique cliques[k] of a chordal graph on n vertices) into the global n × n matrix

A = Σₖ E(Cₖ)ᵀ Yₖ E(Cₖ),

the coupling map of the Fukuda chordal decomposition. Entries shared by several cliques sum the contributions. The adjoint (an analytic ChainRules rrule) scatters the cotangent back to the blocks, so the map differentiates efficiently in both directions.

NonconvexSemidefinite.block_relaxation — Method
block_relaxation(model::VecModel, blocks; labels = nothing)

Replace each selected semidefinite component P(x) ⪰ 0 of model's function-in-set constraints with one SetProduct of per-block PSDCone constraints on the principal submatrices P(x)[C, C], one for every block C of the collection. The component is evaluated once per call and all blocks are sliced from that single evaluation; the non-PSD components of each rewritten bundle are kept.

This is a relaxation

A PSD matrix has PSD principal submatrices, but the converse fails in general: P(x)[C, C] ⪰ 0 for every block is only implied by P(x) ⪰ 0. The rewritten model is therefore a RELAXATION — its feasible set contains the original one, and for minimization its optimal value is a lower bound. Use chordal_transform for the exact Fukuda conversion of a chordal sparsity pattern.

The blocks can come from anywhere: the maximal cliques of a chordal extension (chordal_extension), the per-element degree-of-freedom blocks of a Ferrite mesh (see element_blocks in the Ferrite extension), or any hand-crafted partition. Blocks may overlap and need not cover every index.

blocks is one block collection per PSD component of the model's set constraints, in order; each collection is a vector of index vectors into the component's rows (1:s.dim). A single collection may be passed when the model has exactly one PSD component.

labels selects which constraints to rewrite: only PSD components whose constraint flags intersect labels are replaced (labels = nothing selects all). The unselected constraints are kept unchanged.

NonconvexSemidefinite.chordal_decompose — Method
chordal_decompose(model::VecModel, patterns; x0 = nothing)
chordal_decompose(model::VecModel; x0)

Replace each semidefinite constraint P(x) ⪰ 0 of model with a single BlockSDConstraint whose function evaluates P once and returns every maximal-clique submatrix P(x)[C, C] of a chordal extension of the constraint's sparsity pattern.

This is a relaxation

The clique-submatrix constraints are only implied by P ⪰ 0; the converse fails in general (e.g. tridiag(1, 1, 1) has positive semidefinite 2×2 clique submatrices yet is indefinite). The rewritten model is therefore a RELAXATION: its feasible set contains the original one, and for minimization its optimal value is a lower bound. For element-assembled matrices whose element blocks are rank-one (e.g. truss stiffness matrices) the element-wise form is exact. Use chordal_transform for the exact Fukuda conversion.

patterns is a vector with one sparsity pattern per semidefinite constraint (or a single pattern when the model has one constraint). Entries may be nothing to probe the sparsity of the constraint at x0 (the union of the structural AD dependence pattern and the numerical support of P(x0)).

If x0 is provided, every nonzero entry of P(x0) must lie inside the pattern, otherwise an error is thrown: sparsity exploitation is only valid when the pattern covers all entries the constraint can have.

NonconvexSemidefinite.chordal_extension — Method
chordal_extension(pattern::SparseMatrixCSC; alg = AMDAlg())

The maximal cliques of a chordal extension of the graph of the sparsity pattern, as a vector of index vectors in the original vertex ordering. Every edge of pattern is covered by at least one clique, and the clique graph is chordal. On a chordal pattern the extension is the pattern itself (no fill). The alg keyword selects the ordering (see AbstractChordalAlgorithm).

NonconvexSemidefinite.chordal_projection — Method
chordal_projection(P, cliques; ρ = 1.0, max_iters = 2000, tol = 1e-10)

The projection of the symmetric matrix P onto the chordal-PSD cone of the (chordal) clique structure cliques: the closest matrix A = Σₖ EₖᵀỸₖEₖ with Ỹₖ ⪰ 0, computed by the ADMM fixed point.

The function carries an implicit derivative: the pullback iterates the transposed linearized ADMM steps (the adjoint of the fixed-point map), so gradients match the projection derivative without tracing the iterates.

P ⪰ 0 with a chordal sparsity pattern iff the projection reproduces P (the distance vanishes) — the exact chordal feasibility certificate.

NonconvexSemidefinite.chordal_transform — Method
chordal_transform(model::VecModel, patterns; x0 = model.init, labels = nothing)

The exact chordal decomposition of the semidefinite components of model's function-in-set constraints: each selected PSDCone component with a chordal sparsity pattern is rewritten with the Fukuda conversion — one small PSD variable block per maximal clique of the chordal extension, coupled to the original matrix by linear equalities on the entries of the extension pattern (P = Σₖ E(Cₖ)ᵀ Yₖ E(Cₖ), Yₖ ⪰ 0). The reformulation is equivalent to P(x) ⪰ 0. The coupling is written in normalized units at the formulation level: the clique variables are the normalized decomposition Ỹₖ = Yₖ/sc with sc = max |P(x0)[i, j]|, coupled by P(x)/sc = Σₖ E(Cₖ)ᵀ Ỹₖ E(Cₖ), Ỹₖ ⪰ 0 — an exact scaling, so the residuals and block variables stay O(1) and no solver-side scaling is needed.

patterns is a vector with one sparsity pattern per PSD component of the model's set constraints, in order (an entry may be nothing to probe the pattern at x0); each pattern's graph is completed to a chordal extension with chordal_extension. Every nonzero entry of the component at x0 must lie inside the chordal extension, otherwise an error is thrown: sparsity exploitation is only valid when the pattern covers all entries the component can have.

labels selects which constraints to decompose: only PSD components whose constraint flags intersect labels are rewritten (labels = nothing selects all). The non-PSD components and the unselected constraints are kept.

Returns (dmodel, d0, mapper) where dmodel is the transformed VecModel (the original variables first, then one PSDCone block per clique), d0 its initial point, and mapper extracts the original variables from a transformed point.

NonconvexSemidefinite.decompress_symmetric — Method
decompress_symmetric

For example: a 3*3 positive semidefinite matrix: [ a b d; b c e; d e f ] represents by: [ x_D[1] x_L[1] x_L[2]; x_L[1] x_D[2] x_L[3]; x_L[2] x_L[3] x_D[3] ]

  • x_L::AbstractArray: representing lower triangular part of a n*n matrix, length should be (n^2-n)÷2
  • x_D::AbstractArray: representing diagonal part of a n*n matrix, length should be n
NonconvexSemidefinite.element_blocks — Function
element_blocks(dh::Ferrite.AbstractDofHandler)
element_blocks(grid::Ferrite.AbstractGrid, dh::Ferrite.AbstractDofHandler)

The per-element degree-of-freedom blocks of a finite-element mesh: one index vector per cell, containing the degrees of freedom of that cell. Provided by the Ferrite extension: load Ferrite to enable it. Together with block_relaxation this gives the element-based semidefinite relaxation of an assembled PSD constraint P(x) ⪰ 0:

dm = block_relaxation(model, element_blocks(dh))

The rewritten model enforces P(x)[C, C] ⪰ 0 on every element block C — a relaxation of the assembled constraint, as documented in block_relaxation. For an element-assembled matrix P(x) = Σₑ Eₑᵀ Pₑ(x) Eₑ whose element blocks have rank one (e.g. truss stiffness matrices) the element-wise form is exact.

NonconvexSemidefinite.is_chordal — Method
is_chordal(pattern::SparseMatrixCSC)

Whether the graph of the sparsity pattern (symmetrized, diagonal included) is chordal: every cycle of length ≥ 4 has a chord. Implemented with Maximum Cardinality Search (Tarjan–Yannakakis 1984): the reverse of an MCS numbering is a perfect elimination ordering exactly when the graph is chordal, so the test is to run MCS and verify that for every vertex its earlier MCS neighbors form a clique. O(n + m) up to the clique checks. Loading the optional CliqueTrees.jl package uses its ischordal instead.

A chordal pattern's chordal extension (see chordal_extension) is itself — the decomposition introduces no fill and the maximal cliques are those of the original graph.

NonconvexSemidefinite.ks_aggregate — Method
ks_aggregate(A, B, k, ρ; step=0.0, ratio=false, eigsolver=nothing)

The Kreisselmeier–Steinhauser approximation of the minimum of the k algebraically smallest generalized eigenvalues λ₁ ≤ … ≤ λₖ of the symmetric pencil A·x = λ·B·x (A, B symmetric, B positive definite). Two one-sided logsumexp aggregates bound the minimum — the eigenvalues may be negative (e.g. the ν's of the buckling pencil):

  • the lower bound on min (default, step = 0): KS = -(1/ρ)·log(Σᵢ exp(-ρλᵢ)) — KS ≤ λ₁, KS → λ₁ as ρ → ∞;
  • the negative upper bound on the negative eigenvalues (step = 1): KS = -(1/ρ)·log(Σᵢ exp(ρλᵢ)) — KS ≥ λ₁ whenever the λᵢ are negative;
  • 0 < step < 1: the convex combination KS = (1-step)·lower + step·upper — a step between the lower and upper bounds on the minimum;
  • ratio = true: KS = upper − lower = (1/ρ)·log(Σexp(-ρλᵢ)/Σexp(ρλᵢ)), a surrogate for the spread of the smallest eigenvalues.

The reverse rule is the closed-form eigenvalue sensitivity: with the B-normalized eigenvectors vᵢ (vᵢᵀBvᵢ = 1), dλᵢ = vᵢᵀ(dA − λᵢdB)vᵢ, weighted per mode by wᵢ = (1-step)·softmax(-ρλ)ᵢ − step·softmax(ρλ)ᵢ; the cotangents are

ΔA = Σᵢ Δ·wᵢ·vᵢvᵢᵀ,     ΔB = Σᵢ Δ·wᵢ·(−λᵢ)·vᵢvᵢᵀ,

constructed as sparse matrices when A/B are sparse. The outer-product cotangents are populated over the full vector space (O(k·n²)), so the matrix-level rule targets small-to-moderate problems; large sparse pencils should compose through element-level rules instead.

The eigenpairs come from LOBPCG by default — lobpcg(A, B, false, X0) for the smallest generalized eigenvalues, B-orthonormal vectors — and can be replaced with any eigsolver(A, B, k) -> (λs, vectors), e.g. a dense eigen for testing.

NonconvexSemidefinite.partition_blocks — Method
partition_blocks(P::AbstractMatrix, blocks)

The block partition of a matrix: blocks is a collection of index vectors (one per subdomain/element), and the result is the collection of principal submatrices P[I, I] for I ∈ blocks. Defined with an analytic rrule: the cotangents of the blocks scatter-add back into a cotangent for P — a sparse cotangent when P is sparse, so the reverse cost is the number of gathered entries, and overlapping blocks accumulate.

This is the partition primitive behind the SDD/element relaxations of a matrix-valued function: composing it with an rrule'd matrix function propagates the block derivatives back to the sparse matrix in one rule, without traced per-block loops.

NonconvexSemidefinite.project_psd — Method
project_psd(A::AbstractMatrix)

Orthogonal projection of the symmetric part of A onto the cone of positive semidefinite matrices. If A = U Λ Uᵀ is a symmetric eigendecomposition, the projection is U max(Λ, 0) Uᵀ.

NonconvexSemidefinite.project_psd_batch — Method
project_psd_batch(A::AbstractArray{T,3})

Batched orthogonal projection onto the PSD cone: projects every slice A[:, :, k] with project_psd. One primitive with one analytic rrule so reverse-mode AD sees a single node: the pullback propagates the cotangents to all slices at once (each slice uses the spectral differential of its own decomposition).

NonconvexSemidefinite.project_psd_neg — Method
project_psd_neg(A::AbstractMatrix)

Orthogonal projection of the symmetric part of A onto the cone of negative semidefinite matrices, computed via the Moreau decomposition Π_{S₋ⁿ}(A) = A - Π_{S₊ⁿ}(A).

NonconvexSemidefinite.psd_infeasibility — Method
psd_infeasibility(P::AbstractMatrix)

Distance of the symmetric part of P from the cone of positive semidefinite matrices, i.e. ‖Π_{S₋ⁿ}(P)‖_F (the Frobenius norm of the negative eigenvalues). Returns 0 if and only if P is positive semidefinite.

NonconvexSemidefinite.psd_infeasibility_batch — Method
psd_infeasibility_batch(W::AbstractArray{T,3})

Batched PSD violation metric: ‖Π_{S₋ⁿ}(W[:, :, k])‖_F for every slice, computed from the low-rank negative eigenpairs of each slice (see psd_neg_eig) — no full projection matrices are materialized.

NonconvexSemidefinite.psd_neg_eig — Method
psd_neg_eig(W::AbstractMatrix)

The negative-eigenvalue part of the symmetric part of W as low-rank factors (U₋, λ₋): Π_{S₋ⁿ}(W) = U₋·Diagonal(max(λ₋, 0))·U₋ᵀ. No dense projection matrix is formed — only the negative eigenpairs are kept, which is all the PSD violation metric and its derivatives need (the metric is ‖λ₋‖₂ and its cotangent is the low-rank matrix 2·Π₋(W)).

NonconvexSemidefinite.sdd_partition — Method
sdd_partition(coords::AbstractMatrix, cell_dofs; n_subdomains = 2)

Partitions a mesh into n_subdomains subdomains for the structured domain decomposition (Kočvara's SDD): coords holds the centroid coordinates of each cell (one row per cell, size(coords, 1) == length(cell_dofs)) and cell_dofs[c] the degrees of freedom of cell c. The cells are split by recursive bisection along the longest coordinate axis; the dofs shared by cells of several subdomains become the interface, the others the interior of their subdomain. Works for any mesh (any cell type); load the optional Ferrite.jl dependency for the sdd_partition(grid, dh) convenience method that reads a Ferrite grid and dof handler.

NonconvexSemidefinite.sdd_transform — Method
sdd_transform(model::VecModel, partition; x0 = model.init, labels = nothing)

Kočvara's structured domain decomposition of the semidefinite components of model's function-in-set constraints: each selected PSDCone component P(x) ⪰ 0 whose dimension matches partition is rewritten as a bundle constraint — the subdomain interior blocks P(x)[I_k, I_k] ⪰ 0 and the interface Schur complement S(x) ⪰ 0 as the PSD components of one SetProduct, so the element assembly behind P runs once per evaluation. The transformation is exact for matrices with the bordered block-diagonal structure of the partition (Schur-complement theorem).

labels selects which constraints to decompose: only PSD components whose constraint flags intersect labels are rewritten (labels = nothing selects all); the other constraints are kept. Returns (dmodel, d0, mapper); no auxiliary variables are introduced, so d0 is the original initial point and mapper the identity.

NonconvexSemidefinite.symmetric_pattern — Method
symmetric_pattern(pattern::SparseMatrixCSC)

Symmetrized structural sparsity pattern of pattern, augmented with the diagonal: entry (i, j) is true whenever pattern[i, j] or pattern[j, i] is structurally nonzero, or i == j.

NonconvexSemidefinite.to_barrier — Method
to_barrier(model, c; selection = BarrierSelection(ineq = false, box = false, sd = true), ε = 1e-6)

Build the sub-model of the barrier method: the selected constraints are removed and encoded in the log-barrier objective (with coefficient vector c, one entry per selected constraint group). The default selection matches the historical SDPBarrierAlg behaviour (semidefinite constraints only).
